# 学生信息管理系统

一个基于 Python 开发的命令行学生信息管理系统。

## 项目功能

- 添加学生
- 查看所有学生
- 查询学生
- 修改学生
- 删除学生
- 成绩统计
- 成绩排行榜
- HTTP/API 测试
- SQLite 数据库存储

## 技术栈

- Python
- SQLite
- SQL
- Pandas
- Requests
