# 学习指南：从命令行程序到 FastAPI 网页系统

这份指南面向已经理解 Python 基础和命令行版本、正在学习后端开发的同学。

## 推荐顺序

1. 阅读 `database.py` 和 `test_database.py`，理解 SQLite 增删改查与测试。
2. 阅读 `webapp/security.py`，理解密码为什么不能明文保存。
3. 阅读 `webapp/services.py`，观察业务规则如何脱离网页独立存在。
4. 阅读 `webapp/main.py` 的登录、学生管理、统计和权限路由。
5. 阅读 `webapp/templates/`，理解后端数据如何渲染成网页。
6. 运行 `test_webapp.py`，再故意修改一个判断，观察测试如何发现问题。

## 第一阶段练习

- 把“优秀”阈值从 85 改为 90，并同步修改测试期望。
- 给学生搜索增加年龄条件。
- 在审计日志中筛选某个用户的操作。
- 新增一个只允许管理员访问的系统信息页面。

## 面试时需要能说明

- FastAPI 路由如何接收表单并返回响应。
- Session、CSRF 和角色权限分别解决什么问题。
- 为什么业务计算放到 `services.py`，而不是全部写在路由里。
- Excel 导入为什么要校验表头、数据范围和重复学号。
- 自动测试如何防止修改权限逻辑时引入回归。
