# 数据分析说明

## 平均分与及格率

平均分描述整体水平，但会受到极端值影响；及格率直接反映达到最低要求的比例。系统同时展示两者，避免单一指标误导。

## 标准差

标准差衡量成绩离散程度。平均分相同的两个班级，标准差更大的班级内部差异更明显，教师可能需要分层辅导。

## 趋势

学生趋势按考试日期排序，用最后一次成绩减第一次成绩判断总体方向。两次以上连续下降会触发独立风险原因。

## 风险规则

当前规则使用“累计两次及以上不及格”和“成绩连续下降”。规则可解释、可测试，也能说明为什么没有直接使用黑盒机器学习模型。

## Pandas 在项目中的职责

`webapp/analytics.py` 把数据库查询结果转换为 DataFrame，再完成排序、缺失值检查和聚合。数据库负责可靠存储，Pandas 负责批量分析，两者职责不同。
